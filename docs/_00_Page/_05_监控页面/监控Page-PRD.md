# 监控页面

## 1. 页面功能

监控页面展示系统的运行状态和健康信息，包括系统依赖组件的健康状态、宿主机资源使用情况、Token 使用情况。用户可在此页面实时了解系统的运行状况。

## 2. 布局

### 2.1. 整体结构

页面从上到下分为三个区域：
1. **组件健康状态区**：位于页面顶部，展示系统依赖组件的健康状态；
2. **资源使用区**：位于中部，展示宿主机的 CPU、内存、磁盘使用情况；
3. **Token 使用区**：位于底部，展示 Token 的使用统计；

---

### 2.2. 组件健康状态区

#### 位置
- 位于页面顶部；

#### 布局
- 以卡片网格形式展示各组件的健康状态，每行 3-4 个卡片；

#### 组件卡片
每个组件卡片包含以下信息：
1. **组件名称**：如 LLM Provider、MCP、RelationDB、GraphDB、VectorDB、MQ 等；
2. **状态指示灯**：
   - 绿色圆点：健康（HEALTHY）
   - 黄色圆点：警告（WARNING）
   - 红色圆点：异常（ERROR）
3. **状态文字**：HEALTHY / WARNING / ERROR；
4. **响应时间**：组件的最近响应时间（毫秒）；
5. **详细信息**：点击卡片展开查看详细信息（连接数、错误率等）；

#### 监控的组件列表

| 组件 | 监控指标 | 说明 |
|------|---------|------|
| LLM Provider | 连接状态、响应时间 | 各 LLM 提供商的健康状态 |
| MCP | 进程状态、响应时间 | 已安装 MCP 的运行状态 |
| RelationDB | 连接状态、查询响应时间 | 关系数据库（SQLite）健康状态 |
| GraphDB | 连接状态、节点/边数量 | 图数据库健康状态 |
| VectorDB | 连接状态、向量数量 | 向量数据库健康状态 |
| MQ | 队列状态、积压消息数 | 消息队列健康状态 |

#### 调用接口
- 调用各 Provider 的 visualized 接口获取健康状态（visualizedDB / visualizedGraph / visualizedVector）；

---

### 2.3. 资源使用区

#### 位置
- 位于组件健康状态区下方；

#### 布局
- 以三个数据卡片并排展示 CPU、内存、磁盘的使用情况；

#### CPU 使用率卡片
1. **环形进度图**：显示当前 CPU 使用率百分比；
2. **数值显示**：如"45%"；
3. **核心数**：显示 CPU 核心数；
4. **负载均值**：显示 1/5/15 分钟负载均值；

#### 内存使用率卡片
1. **环形进度图**：显示当前内存使用率百分比；
2. **数值显示**：如"4.2GB / 16GB"；
3. **已用/总量**：显示已用内存和总内存；

#### 磁盘使用率卡片
1. **环形进度图**：显示当前磁盘使用率百分比；
2. **数值显示**：如"120GB / 500GB"；
3. **已用/总量**：显示已用磁盘空间和总磁盘空间；
4. **数据目录**：显示系统数据目录的磁盘占用；

#### 颜色规范
- 使用率 < 70%：绿色；
- 使用率 70%-90%：黄色；
- 使用率 > 90%：红色；

#### 调用接口
- 调用 System Application 的资源监控接口获取宿主机资源使用情况；

---

### 2.4. Token 使用区

#### 位置
- 位于资源使用区下方；

#### 布局

##### Token 使用统计卡片
- 以四个数据卡片并排展示 Token 使用统计：
  1. **今日 Token 用量**：今日累计使用的 Token 数量；
  2. **本月 Token 用量**：本月累计使用的 Token 数量；
  3. **今日请求次数**：今日的 LLM 调用次数；
  4. **平均响应时间**：LLM 平均响应时间（毫秒）；

##### Token 使用趋势图
- 折线图展示近 7 天/30 天的 Token 使用趋势；
- X 轴为日期，Y 轴为 Token 数量；
- 支持切换时间范围（7天 / 30天 / 90天）；

##### 各模型 Token 分布
- 柱状图展示各模型的 Token 使用占比；
- X 轴为模型名称，Y 轴为 Token 数量；

#### 调用接口
- 调用 System Application 或 Analytics Application 的统计接口获取 Token 使用数据；

---

### 2.5. 自动刷新

- 监控页面数据支持自动刷新，默认每 30 秒刷新一次；
- 页面右上角显示"最后更新时间"和手动刷新按钮；
- 自动刷新可由用户开关控制；

---

### 2.6. 告警提示

- 当组件状态为 ERROR 或资源使用率超过 90% 时，页面顶部显示告警横幅；
- 告警横幅包含：告警组件名称、告警级别、告警时间、告警详情；
- 告警横幅可手动关闭，但下次刷新若仍异常会再次显示；
