# Config 页面

## 布局

采用分层展示的方式，每一层占据整个功能区的范围；
通过颜色来区分是否可以进行配置，绿色表示这个模块有配置可以进行配置；灰色表示这个模块不能进行配置；

### 分层说明

#### 第一层 整体框架层

调用config Application 的configDetail接口获取整个系统所有分层，分模块，模块配置分类，具体配置的信息；

1. 展示的是系统的整体框架图；
2. 框架图分层；
3. 每一层具有若干模块，独立展示；
4. 每一个模块的若干个配置分类也要独立展示；

整个展示的风格可以参考矩形分块图；

分层，分模块，模块配置分类，配置都需要有配置"可读","可写"的按钮用来控制展示和访问；

#### 第二层 分层区（通过点击具体的分层，进入指定的分层）

以卡片的形式展示分层中每一个模块

##### 第三层 模块区（通过点击具体的模块，进入指定的模块）

以卡片的形式展示模块中的配置分类；

##### 第四层 配置区（通过点击具体的配置分类，进入指定的配置分类）

以卡片的列表的形式展示配置分类中的具体配置；

##### 第五层 配置读写区（通过点击具体的配置，进入指定的配置）

以弹窗的形式展示配置的内容，通过修改配置后可以通过点击"提交"进行更新；

**注意**：所有的配置方式分散在具体的模块中；
