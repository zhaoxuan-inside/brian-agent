# 配置页面

## 1. 页面功能

配置页面以分层展示的方式管理系统的所有配置项。通过五层架构（整体框架层 -> 分层区 -> 模块区 -> 配置区 -> 配置读写区）逐级浏览和修改系统配置。通过颜色区分配置的可配置状态，绿色表示可配置，灰色表示不可配置。

## 2. 布局

### 2.1. 整体结构

采用分层展示的方式，每一层占据整个功能区的范围。用户通过点击逐级进入下一层，支持面包屑导航返回上层。

### 2.2. 颜色规范

- **绿色**：该模块/配置有配置项且可进行配置；
- **灰色**：该模块/配置不可进行配置；
- 通过颜色直观区分配置的可访问性；

---

### 2.3. 第一层：整体框架层

#### 功能
- 展示系统的整体框架图，包括所有分层、模块、配置分类和具体配置；

#### 数据来源
- 调用 Config Application 的 getConfigDetail 接口获取整个系统所有分层、分模块、模块配置分类、具体配置的信息；

#### 布局
- 以矩形分块图的形式展示整体框架；
- 框架图分层展示，每一层为一个横向区域；
- 每一层具有若干模块，以独立矩形块展示；
- 每一个模块的若干个配置分类也独立展示（以小矩形块嵌套在模块块内）；
- 分层、分模块、模块配置分类、配置都需要有"可读"、"可写"的按钮用来控制展示和访问；

#### 交互
- 点击具体的分层矩形块，进入第二层（分层区）；
- 点击面包屑"整体框架"返回第一层；

---

### 2.4. 第二层：分层区

#### 进入方式
- 通过点击第一层中的具体分层进入；

#### 布局
- 以卡片网格的形式展示该分层中的每一个模块；
- 每个模块卡片包含：模块名称、模块描述、配置分类数量、可配置标识（绿色/灰色）；

#### 交互
- 点击具体的模块卡片，进入第三层（模块区）；
- 点击面包屑返回第一层；

---

### 2.5. 第三层：模块区

#### 进入方式
- 通过点击第二层中的具体模块卡片进入；

#### 布局
- 以卡片网格的形式展示模块中的配置分类；
- 每个配置分类卡片包含：分类名称、分类描述、配置项数量、可配置标识；

#### 交互
- 点击具体的配置分类卡片，进入第四层（配置区）；
- 点击面包屑返回第二层；

---

### 2.6. 第四层：配置区

#### 进入方式
- 通过点击第三层中的具体配置分类卡片进入；

#### 布局
- 以卡片列表的形式展示配置分类中的具体配置项；
- 每个配置项卡片包含：配置名称、配置描述、当前值摘要、可配置标识；

#### 交互
- 点击具体的配置项卡片，进入第五层（配置读写区）；
- 点击面包屑返回第三层；

---

### 2.7. 第五层：配置读写区

#### 进入方式
- 通过点击第四层中的具体配置项卡片进入；

#### 布局
- 以弹窗的形式展示配置的内容；
- 弹窗内容：配置名称、配置描述、配置表单（根据配置类型展示不同的表单控件）；
- 弹窗底部：取消按钮 + 提交按钮；

#### 表单控件类型
- **文本输入框**：用于字符串类型配置（如 URL、API Key）；
- **数字输入框**：用于数值类型配置（如超时时间、最大重试次数）；
- **下拉选择框**：用于枚举类型配置（如模型类型、策略类型）；
- **开关按钮**：用于布尔类型配置（如启用/禁用）；
- **JSON 编辑器**：用于复杂结构配置（如策略 JSON、Soul 配置）；

#### 交互
- 修改配置后点击"提交"按钮，调用 Config Application 的 updateConfigPrivilege 或 manageLLMProvider 等接口更新配置；
- 点击"取消"按钮关闭弹窗，不保存修改；
- 提交成功后显示成功提示，并关闭弹窗；

---

### 2.8. 具体配置模块说明

配置页面涵盖以下配置模块，每个模块对应系统中的一个功能组件：

| 模块 | 配置内容 | 对应路由 |
|------|---------|---------|
| LLM 模型 | LLM 提供商管理、模型启用/禁用、默认模型设置、连接测试 | /models |
| Soul | Soul 的增删改查、Soul 内容编辑 | /soul |
| Work | Work 配置管理 | /work |
| Skill | Skill 的增删改查、Skill 内容编辑 | /skill |
| MCP | MCP 提供商管理、MCP 安装/卸载、MCP 启停 | - |
| Agent | 自定义 Agent 的增删改查、Agent 配置 | /agent |

**注意**：所有的配置方式分散在具体的模块中，用户可通过导航图标直接进入具体模块页面进行配置，也可通过配置页面的五层架构逐级浏览；

---

### 2.9. 面包屑导航

- 页面顶部显示面包屑导航，标识当前所在的层级路径；
- 格式：整体框架 > [分层名] > [模块名] > [配置分类名] > [配置名]；
- 点击面包屑中的任意层级名称可快速返回该层级；
