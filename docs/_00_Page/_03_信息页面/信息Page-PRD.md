# 信息展示页面

## 页面功能

以合理的方式展示整个系统的信息

## 信息分类

1. 用户的问答信息；
2. 用户的资料库；
3. Tag的关联图；
4. 关键词图；

## 布局

采用TAB展示的方式，每一类信息占据整个功能区的范围；

### 信息展示说明

#### 用户问答信息（记忆）

以时间为维度倒序展示用户的所有的问答内容；
左侧为一个时间轴，可以通过拖动时间轴来实现不同时间的问答信息展示；
按照work_id作为节点来分节点展示；

#### 用户的资料库

每一个资料库以卡片的形式展示；第一个资料为为添加资料库的卡片；卡片上面有删除按钮；
用户配置资料库在本机的路径，配置确认前需要检查路径是否存在是否具有权限；
资料库卡片可以点击进入以卡片的形式展示资料库中的所有markdown文件；
点击具体的markdown文件可以查看markdown内容（需要进行内容渲染）；

#### Tag的关系图

通过canvas图展示系统中的所有tag，tag之间的联系，鼠标放在边上还可以看到边中的权重，点击一个具体的tag会自动居中；tag的大小通过tag的激活次数决定；大小要注意和谐，最大和最小不能差距太大；
可以通过tag查看关来呢的问答内容列表；

#### 关键词图

canvas以圆形展示关键词，圆形的大小有关键词的激活次数决定；点击关键词可以看到关联的信息；
