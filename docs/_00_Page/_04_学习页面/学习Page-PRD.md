# 学习页面

## 1. 页面功能

以合理的方式展示学习的相关信息，包括学习控制（手动开始/暂停学习、配置随机因子触发学习）、学习进度展示、学习成果展示。用户可在此页面管理自学习任务和查看学习结果。

## 2. 布局

### 2.1. 整体结构

页面从上到下分为三个区域：
1. **学习控制区**：位于页面顶部，提供学习控制按钮和配置；
2. **学习进度区**：位于中部，展示当前学习任务的执行进度；
3. **学习成果区**：位于底部，展示学习到的知识和洞察；

---

### 2.2. 学习控制区

#### 位置
- 位于页面顶部；

#### 布局
- 水平排列的控制面板，包含以下控件：

##### 开始/暂停学习按钮
- **开始学习**：绿色按钮，点击调用 Learning Application 的 startLearning 接口启动学习；
- **暂停学习**：橙色按钮，点击调用 Learning Application 的 stopLearning 接口暂停学习；
- 按钮状态根据当前学习状态自动切换；

##### 随机因子配置
- **随机因子滑块**：范围 0-100，控制随机触发学习的概率；
- **说明文字**：数值越大，随机触发学习的频率越高；
- 修改后调用 Learning Application 的 configDriverWeights 接口更新配置；

##### 学习模式选择
- **下拉选择框**：选择学习模式（从对话学习 / 从文档学习 / Tag图维护）；
- 选择"从对话学习"时，系统从用户对话中提取知识；
- 选择"从文档学习"时，系统从资料库文档中提取知识；
- 选择"Tag图维护"时，系统维护 Tag 相似性连接；

---

### 2.3. 学习进度区

#### 位置
- 位于学习控制区下方；

#### 布局

##### 当前任务卡片
- 展示当前正在执行的学习任务：
  1. **任务名称**：如"从对话学习"、"Tag图相似性维护"等；
  2. **任务状态**：RUNNING / FINISH / FAILURE（带状态颜色标识）；
  3. **进度条**：水平进度条，显示任务进度百分比（0-100%）；
  4. **开始时间**：任务开始执行的时间；

##### 学习任务队列
- 以列表形式展示待执行的学习任务；
- 每个任务项包含：任务名称、任务摘要、计划执行时间、任务状态；
- 调用 Learning Application 的 soLearningTask 接口获取任务列表；

##### 内置学习任务
- 展示系统内置的自学习任务（不可删除）：
  1. 信息标签图相似性维护；
  2. 信息标签图相似性连接建立；
  3. 信息标签图不常用连接老化；
  4. 随机获取用户消息建立用户画像；
- 每个内置任务展示：任务名称、任务摘要、执行周期（cron）、上次执行时间、下次执行时间；

#### 调用接口
- 调用 Learning Application 的 getLearningProgress 接口获取进度；
- 调用 SelfLearning Application 的 searchLibrary 接口获取资料库列表；

---

### 2.4. 学习成果区

#### 位置
- 位于学习进度区下方；

#### 布局

##### 知识列表
- 以卡片列表形式展示学习到的知识点；
- 每个知识卡片包含：
  1. **知识内容**：学习到的知识点摘要；
  2. **来源**：知识的来源（对话/文档）；
  3. **学习时间**：知识点被学习到的时间；
  4. **关联Tag**：知识点关联的 Tag 标签；
- 支持分页加载；

##### 洞察列表
- 以卡片列表形式展示学习产生的洞察；
- 每个洞察卡片包含：
  1. **洞察内容**：洞察摘要；
  2. **洞察类型**：如"模式识别"、"趋势分析"、"异常检测"等；
  3. **生成时间**：洞察生成的时间；
- 支持分页加载；

#### 调用接口
- 调用 Learning Application 的搜索接口获取学习成果；
- 调用 Info Application 的搜索接口获取知识点详情；

---

### 2.5. 学习统计

#### 位置
- 位于学习成果区上方或右侧；

#### 布局
- 以数据卡片形式展示学习统计信息：
  1. **总学习次数**：累计学习次数；
  2. **知识点总数**：学习到的知识点总数；
  3. **洞察总数**：生成的洞察总数；
  4. **本周学习次数**：本周的学习次数；
