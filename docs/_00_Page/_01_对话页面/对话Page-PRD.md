# 对话页面

## 1. 页面功能

对话页面是系统的核心交互页面，用户在此页面与 Brian Agent 进行对话。页面包含对话输入、消息展示、ChatMap 可视化、会话管理等功能。

## 2. 布局

### 2.1. 整体结构

对话页面从左到右分为两个主要区域：
1. **ChatMap 区**：位于左侧，展示会话内消息的引用关系图；
2. **对话区**：位于右侧，展示当前会话的消息列表和输入框；

两个区域之间支持拖拽调整宽度比例（ResizableDivider）。

---

### 2.2. 对话输入区

#### 位置
- 位于对话区底部，居中显示；
- 宽度占对话区宽度的 80%；

#### 布局
- 圆角矩形容器，内部从左到右排列：输入框 + 发送按钮；
- 输入框占据大部分宽度，发送按钮固定在右侧；

#### 输入框
- **占位文本**：显示"输入消息..."提示；
- **多行输入**：支持多行文本输入，输入框高度随内容自动扩展，最大高度不超过 200px；
- **键盘快捷键**：Enter 发送消息，Shift+Enter 换行；
- **引用消息**：当用户选中了历史消息（通过复选框），输入框上方显示引用的消息摘要标签，可点击 × 取消引用；

#### 发送按钮
- **默认状态**：蓝色图标按钮，图标为发送箭头；
- **禁用状态**：当输入框为空时，按钮禁用（灰色）；
- **加载状态**：消息发送后 Agent 处理中时，按钮显示加载动画；

#### 交互
- 点击发送按钮或按 Enter 键，调用 Chat Application 的 submitWork 接口发送消息；
- 发送时入参：session_id（当前会话）、msg_content（输入内容）、citing_msg_ids（引用消息 ID 列表）；
- 发送后清空输入框内容；

---

### 2.3. ChatMap 区

#### 位置
- 位于对话区左侧；
- 宽度可通过拖拽分隔线调整，默认占页面宽度的 40%；

#### 功能
- 基于 Canvas 建立信息气泡的引用关系图；
- 以可视化方式展示当前会话内所有消息的引用关系；

#### 卡片样式
- 圆角矩形卡片，统一大小（约 160px × 100px）；
- 卡片内容布局：
  1. **左上角**：信息时间戳（格式：HH:mm）；
  2. **右上角**：复选框，用于建立卡片之间的引用关系；
  3. **卡片内容主区**：展示消息摘要（不超过 50 字符，超出截断显示...）；
  4. **左下角**：小圆角矩形标签，显示本卡片被引用的数量；
  5. **右下角**：> 箭头按钮，点击查看对话详情（跳转到对话区对应消息位置并高亮）；

#### 卡片排布规则
- **回复关系**的卡片采用上下排布（同一会话线程中的连续消息）；
- **引用关系**的卡片采用左右排布（用户引用了之前某条消息发起新提问）；
- **箭头方向**：从被引用方指向引用方；
- **箭头样式**：带箭头的曲线，颜色为浅灰色；

#### 卡片上边功能
- 吸附在卡片的上边外侧；
- **Agent 编排 DAG 图按钮**：点击按钮弹窗展示基于 Canvas 的 Agent 编排 DAG 图，展示本次工作经过的 Agent 链路（PlannerAgent -> WorkAgent -> WriterAgent -> EvolutorAgent）；

#### Canvas 交互
- 支持鼠标拖拽平移视图；
- 支持鼠标滚轮缩放；
- 点击卡片高亮该卡片并在对话区定位对应消息；

---

### 2.4. 对话区

#### 位置
- 位于 ChatMap 区右侧；
- 宽度可通过拖拽分隔线调整，默认占页面宽度的 60%；

#### 布局
- 从上到下分为：消息列表区 + 对话输入区；
- 消息列表区占据对话区大部分高度，支持纵向滚动；

#### 消息列表

##### 消息排列
- 按时间序列展示一个会话内部的所有消息；
- 用户发送的消息靠左对齐；
- 系统回复的消息靠右对齐；

##### 用户消息气泡
- 圆角矩形气泡，背景色为浅蓝色；
- 气泡内容布局：
  1. **左上角**：信息时间戳（格式：HH:mm）；
  2. **右上角**：复选框，用于建立消息引用关系；
  3. **气泡内容主区**：展示完整的用户消息内容；
  4. **左下角**：小圆角矩形标签，显示本消息被引用的数量；

##### 系统回复消息气泡
- 圆角矩形气泡，背景色为白色（浅色模式）/深灰色（深色模式）；
- 气泡内容布局与用户消息气泡相同；
- 支持流式显示（SSE 推送内容逐字/逐块显示）；

##### Thinking 消息
- 系统回复中的非最终 Response 消息（如 Agent 思考过程、工具调用记录等）；
- 采用折叠面板样式展示，默认折叠；
- 折叠状态显示：Thinking... 标签 + 展开箭头；
- 展开后显示：Agent 名称、思考步骤、工具调用详情、耗时等；
- Thinking 消息与回复消息采用不同的视觉样式（Thinking 消息为半透明或带左侧边框标识）；

##### 流式显示（SSE）
- 系统回复消息通过 SSE 流式推送，前端逐字符/逐块显示；
- SSE 事件类型：
  - `loading`：Agent 正在处理，显示加载动画；
  - `agent_thinking`：Agent 思考过程内容，更新 Thinking 面板；
  - `agent_created`：Agent 已创建，显示 Agent 信息；
  - `agent_status`：Agent 状态更新；
  - `agent_output`：Agent 输出内容，更新回复气泡；
  - `text`：最终文本内容，逐块追加到回复气泡；
  - `done`：消息发送完毕，显示 `[end]` 结束标识；

##### 反馈按钮
- 系统回复消息气泡下方显示反馈按钮组；
- **评分按钮**：1-5 星评分，点击调用 Feedback Application 的 addFeedback 接口；
- **点赞/点踩按钮**：快速反馈，点击调用 Feedback Application 的 addFeedback 接口；

### 2.5. 会话列表

#### 入口
- 会话列表按钮位于对话区右上角位置；
- 靠边自动隐藏到侧边，鼠标悬停时显示；

#### 展开布局
- 点击会话列表按钮展开会话列表面板；
- 面板从右侧滑出，覆盖在对话区上方，宽度约 300px；

#### 面板内容

##### 顶部操作区
1. **会话搜索按钮**：点击展开搜索输入框，输入关键词搜索会话（调用 Chat Application 的 searchSession 接口）；
2. **会话创建按钮**：点击调用 Chat Application 的 createSession 接口创建一个新会话，创建后自动切换到新会话；

##### 会话卡片列表
- 按时间倒序展示会话卡片列表（调用 Chat Application 的 searchSession 接口获取会话列表）；
- 滚动加载更多会话；

##### 会话卡片样式
1. 采用圆角矩形；
2. **左上角**：会话的创建时间（格式：YYYY-MM-DD HH:mm）；
3. **会话主题**：左对齐显示，无主题时显示"新会话"；
4. **右上角**：复选框，支持鼠标点击选取，支持全选按钮对当前展示的会话卡片进行勾选，支持全部删除操作；
5. **右端**：删除按钮，红色图标，点击删除该会话（调用 Chat Application 的 deleteSession 接口）；

#### 会话溢出检查
- 切换会话时调用 Chat Application 的 checkSessionOverflow 接口检查会话是否溢出；
- 如果溢出，显示提示信息"会话已达到上限，请创建新会话"；

---

### 2.6. Agent 编排 DAG 弹窗

#### 入口
- 点击 ChatMap 卡片上边的 Agent 编排 DAG 图按钮；

#### 弹窗布局
- 全屏弹窗，背景半透明遮罩；
- 弹窗内容区居中，宽度约 800px，高度约 600px；

#### 弹窗内容
- 基于 Canvas 展示 Agent 编排的 DAG 图；
- DAG 节点为圆角矩形，显示 Agent 名称和类型（Planner/Work/Writer/Evolutor）；
- DAG 边为带箭头的曲线，表示 Agent 执行顺序；
- 点击节点可查看该 Agent 的执行详情（输入、输出、耗时、Token 消耗）；

#### 调用接口
- 调用 Chat Application 的 getChatHistory 或 getAgentChain 接口获取 Agent 链路数据；
