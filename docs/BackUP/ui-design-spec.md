# Brian-Agent UI Design Specification

> Apple风格 · 极简主义 · 精致细节

---

## 一、设计原则

| 原则 | 描述 | 应用场景 |
|------|------|----------|
| **极致留白** | 大量负空间，内容居中呈现 | 主界面、输入框周围 |
| **毛玻璃效果** | 磨砂质感，半透明背景 | 输入框、功能面板 |
| **圆润边角** | 统一28px圆角半径 | 所有容器、按钮 |
| **精准排版** | 严格的字体层级和间距 | 全局文本 |
| **克制色彩** | 黑/白/灰为主，单一强调色 | 全局配色 |
| **细腻动画** | 微动画、平滑过渡、弹性效果 | 所有交互 |
| **触觉反馈** | 点击缩放、阴影变化 | 按钮、图标 |

## 五、核心界面设计

### 5.1 背景设计

#### 5.1.1 神经网络可视化风格

```
设计要素:
- 主体: 抽象神经网络节点和连接
- 节点: 圆形光点，大小随机 (2-8px)
- 连接: 半透明线条，粗细随机 (0.5-1.5px)
- 颜色: 冷色调为主 (深蓝/紫色)，点缀Brian蓝
- 动态: 节点缓慢漂移，连接动态变化

视觉处理:
- 高斯模糊: 40px
- 透明度: 60%
- 叠加层: 渐变遮罩 (顶部20%透明 → 底部80%透明)
- 固定: 点击"记忆"图标时背景保持模糊，不清晰化
```

#### 5.1.2 CSS实现要点

```css
.neural-background {
  background-image: url('/assets/neural-network.svg');
  background-size: cover;
  background-position: center;
  filter: blur(40px);
  opacity: 0.6;
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  height: 100%;
  z-index: -1;
}
```

### 5.2 输入框设计

#### 5.2.1 位置与动画

```
初始状态:
- 位置: 屏幕垂直居中
- 宽度: 50% (最大600px)
- 高度: 56px

交互状态:
- 用户输入并发送第一条消息后
- 动画: 平滑下移至底部视觉美化位置
- 吸附位置: 距离底部60px (非紧贴屏幕边缘)

动画参数:
- 时长: 0.5秒
- 缓动: cubic-bezier(0.34, 1.56, 0.64, 1) (弹性效果)
- 延迟: 消息发送后立即触发
```

#### 5.2.2 外观设计

```
样式:
- 背景: 磨砂玻璃 (rgba(255,255,255,0.3) / rgba(0,0,0,0.3))
- 边框: 1px solid rgba(0,0,0,0.1) (浅色) / rgba(255,255,255,0.1) (深色)
- 圆角: 28px
- 阴影: 0 4px 20px rgba(0,0,0,0.05) (浅色) / 0 4px 20px rgba(0,0,0,0.3) (深色)

内部布局:
- 左侧: Lucide `message-square` 图标 (次要文字色)
- 中间: 输入框，占位文字 "与Brian对话..."
- 右侧: 发送按钮 (Brian蓝圆形)

尺寸:
- 图标间距: 16px
- 按钮尺寸: 40px (圆形)
- 输入框内边距: 16px 20px
```

#### 5.2.3 交互细节

```
聚焦状态:
- 边框: Brian蓝
- 阴影: 0 0 0 3px rgba(0,122,255,0.2)
- 图标: Brian蓝

发送状态:
- 按钮: 发送时缩小至90%，发送后恢复
- 输入框: 发送后清空，显示加载动画

移动端:
- 不考虑移动端适配
- 移动端通过微信等IM以Gateway方式接入
```

### 5.3 右上角功能区

#### 5.3.1 布局设计

```
位置: 右上角，距离顶部20px，距离右侧30px
布局: 水平排列，间距24px

#### 5.3.2 交互设计

```

- 阴影: 0 4px 12px rgba(0,0,0,0.1)
- 颜色: Brian蓝

点击效果:
- 图标缩放: 95% → 恢复
- 选中状态: 图标下方显示2px横线指示器 (Brian蓝)

Tooltip:
- 显示: 悬停0.3秒后显示

### 5.4 功能面板

#### 5.4.1 滑出面板设计

```
位置: 从右侧滑入
宽度: 360px
高度: 100vh

外观:
- 背景: 磨砂玻璃 (rgba(255,255,255,0.8) / rgba(0,0,0,0.8))

- 圆角: 0 (与窗口边缘平齐)

- 滑入: 0.35秒，cubic-bezier(0.32, 0.72, 0, 1)
- 滑出: 0.3秒，cubic-bezier(0.32, 0.72, 0, 1)
- 背景遮罩: 变暗至30%透明度

内部布局:
- 顶部: 标题栏 (24px间距) + 关闭按钮
- 内容区: 滚动容器，16px内边距
- 底部: 版本信息 (11px字号，次要文字色)
```

#### 5.4.2 各面板内容

**记忆面板**:
- 标题: "记忆图谱"
- 内容: 记忆节点可视化卡片
- 操作: 搜索、筛选、删除

**图书馆面板**:
- 标题: "本地资料"
- 内容: 路径列表、添加路径按钮
- 操作: 扫描、索引、删除

**历史面板**:
- 标题: "历史会话"
- 内容: 会话列表 (时间、摘要)
- 操作: 搜索、恢复、删除

**设置面板**:
- 标题: "设置"
- 内容: API配置、隐私设置、外观切换
- 操作: 保存、重置

## 六、多Agent工作链路可视化

### 6.1 架构设计

#### 6.1.1 Agent链数据结构

```typescript
interface AgentNode {
  id: string;
  name: string;
  type: 'root' | 'work' | 'sub';
  status: 'idle' | 'running' | 'completed' | 'failed';
  parentId: string | null;
  children: string[];
  startTime?: number;
  endTime?: number;
  output: string[];
  error?: string;
}

interface AgentChain {
  id: string;
  rootAgent: AgentNode;
  agents: Map<string, AgentNode>;
  createdAt: number;
}
```

#### 6.1.2 实时数据流

```
协议选择: WebSocket (双向通信)

消息格式:
{
  type: 'agent_created' | 'agent_status_change' | 'agent_output' | 'agent_complete',
  payload: AgentNode | AgentOutput
}

更新频率: 输出流每500ms推送一次状态
```

### 6.2 可视化组件

#### 6.2.1 Agent链路树

```
位置: 对话区域右侧，宽度300px
布局: 垂直树状结构
样式:

节点设计:
- 形状: 圆角矩形 (12px圆角)
- 背景: 磨砂玻璃
- 边框: 1px (状态颜色)
- 尺寸: 宽260px，高60px

节点内容:
- 左侧: Agent图标 + 类型标签
- 中间: Agent名称
- 右侧: 状态指示器 (圆形)

连线设计:
- 样式: 虚线 (状态颜色)
- 方向: 从上到下，从左到右
- 宽度: 2px

状态颜色:
- idle: 灰色
- running: Brian蓝 (脉冲动画)
- completed: 绿色
- failed: 红色
```

#### 6.2.2 Agent输出流

```
位置: 对应Agent节点下方
布局: 卡片式，缩进显示

样式:
- 背景: 透明
- 边框: 左侧2px竖线 (状态颜色)
- 圆角: 8px
- 内边距: 12px 16px

内容:
- 时间戳: 右上角，Caption字号
- 输出文本: Body字号，自动换行
- 代码块: 等宽字体，背景深色，圆角4px

交互:
- 折叠/展开: 点击节点切换
- 复制: 右键菜单复制输出
- 上报: 右键菜单上报问题

动画:
- 新输出: 淡入效果 (0.3秒)
- 滚动: 自动滚动到最新输出
```

#### 6.2.3 组件交互

```
展开/折叠:
- 点击Agent节点展开/折叠其输出
- 动画: 0.2秒平滑过渡

状态变化:
- running: 脉冲动画 (每1秒明暗变化)
- completed: 打勾图标
- failed: 错误图标 + 红色闪烁

输出流:
- 实时追加: 新输出自动添加到底部
- 自动滚动: 保持最新输出可见
- 手动滚动: 用户可自由滚动历史
```

## 九、动画规范

### 9.1 页面加载动画

```
序列:
1. 背景图像淡入 (0.5秒)
2. 输入框从底部滑入并弹性回弹 (0.5秒)
3. 功能图标逐一淡入 (每个间隔0.05秒)
4. 标题文字淡入 (0.3秒)

缓动函数:
- 淡入: ease-out
- 滑入: cubic-bezier(0.34, 1.56, 0.64, 1)
```

### 9.2 对话交互动画

```
用户消息:
- 从右侧滑入 (0.3秒)
- 轻微缩放效果

模型消息:
- 打字机效果 (50ms/字)
- 淡入效果叠加
- 评价按钮延迟显示

多Agent:
- Agent节点创建: 缩放出现 (0.2秒)
- 输出流: 淡入 + 上移 (0.3秒)
- 状态变化: 颜色过渡 (0.2秒)
```

### 9.3 面板切换动画

```
滑入:
- 0.35秒，cubic-bezier(0.32, 0.72, 0, 1)

滑出:
- 0.3秒，cubic-bezier(0.32, 0.72, 0, 1)

背景遮罩:
- 淡入/淡出 (0.2秒)

内部元素:
- 逐一淡入 (间隔0.05秒)
```

```
状态分层:
- 全局状态: Theme, UserInfo, ActivePanel
- 会话状态: Messages, AgentChain, InputPosition
- 组件状态: Local UI states

方案: React Context + useReducer
- ThemeContext: 管理明暗模式
- SessionContext: 管理对话和Agent状态
- PanelContext: 管理功能面板状态
```
