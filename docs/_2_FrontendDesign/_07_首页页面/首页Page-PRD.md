# 首页

## 1. 页面功能

产品宣传首页（系统默认落地页，路由 `/`）。面向新用户介绍 Brian-Agent 的核心亮点：记忆地图、记忆成长、思考透明、第二大脑、数据归属；并提供产品展示、对比表、快速上手指引与社区（QQ / 微信群）入口。内容由根目录宣传页 `BrianAgent.html` 移植而来，视觉风格与前端设计体系（apple-gray / brian-blue / glass-panel、明暗主题）对齐。

> 原 4 张静态产品截图（hero-map / memory-pin / tag-graph / keyword-graph.png）已全部替换为前端代码实现的动态展示组件（`src/components/home/`），不再参与打包。

## 2. 布局

### 2.1. 整体结构

页面自上而下分为：
1. **全局 Header**：与其他功能页共用（见 整体页面-PRD）；
2. **锚点子导航**：固定在 Header 下方（sticky），提供页内锚点：记忆地图 / 越长越懂你 / 可见的思考 / 第二大脑 / 数据归属 / 对比 / 交流群，右侧「立即体验」按钮跳转 `/chat`；
3. **内容区块**（单向滚动，均带进入视口渐显动画）：
   - **Hero**：标语「AI 的记忆，不该是黑盒」、动态应用窗口示意（HeroAppShot 组件：左侧 ChatMap 记忆地图——平滑贝塞尔连线 + 点状虚线流动 + solid 连线流动光点 + 节点漂浮 + 点阵背景，**假鼠标演示循环**：移动到消息卡复选框 → 点击勾选（勾选框点亮、卡片描边变蓝、提示气泡「已勾选进本轮上下文」、追问卡「引用 1」胶囊点亮）→ 移动到另一张卡的 Pin 按钮 → 点击钉住（Pin 变橙 + 红色脉冲环、提示气泡「已钉住 · 每轮生效」）→ 复位重播）；右侧对话消息依次浮现 + 输入框光标闪烁；CTA（▸ 现在就试 → `/chat`；看看它长什么样 → 锚点）；
   - **数据统计**：4 项指标（4 种记忆检索维度 / 13+ 家模型提供商 / 100% 数据留在本机 / 0 依赖安装），进入视口时数字滚动动画；
   - **痛点场景**：对话气泡演示（第 50 轮忘了第 3 轮）；
   - **01 记忆地图**：可交互 SVG 示意图（节点悬浮高亮关联连线、平滑贝塞尔连线入场绘制与流动光点）+ Memory Pin 动态示意（MemoryPinShot 组件：钉住消息的 Pin 图标红色高亮脉冲，两条消息渐次浮现）+ 特性清单；
   - **02 越长越懂你**：涌现图 / 关键词图动态示意（GraphShot 组件：真实渲染的 SVG 力导向网络，布局复用 `utils/forceDirectedLayout.ts`（与真实涌现页同款算法）确定性生成；数据按主题簇组织（涌现图：出行天气 / 美食住宿 / Agent 技术 / 面板行业孤岛；关键词图：API / Agent / 存储 / 通用词 + 外围孤点 + external-required-tool 三角），枢纽节点大而偏红（蓝=低频→红=高频）、带光晕，标签带描边晕，节点缓慢漂移、悬浮高亮关联节点与连线）+ 3 张特性卡片；
   - **03 可见的思考**：需求确认弹窗示意 + 执行时间线示意（进入视口后逐步点亮并循环）+ 特性清单；
   - **04 第二大脑**：6 张特性卡片（资料库 / 自学习 / 选中即问 / 洞察 / 主动度 / 用户画像）；
   - **05 数据归属**：4 张特性卡片（全本机 / API Key 自管 / 解压即用 / 开源自建）；
   - **现在就试**：终端打字动画（npm i -g brian-agent …，循环重放）+ GitHub 外链 + 返回亮点锚点；
   - **对比表**：8 行「常见聊天产品 vs Brian-Agent」对比；
   - **交流群**：QQ 群二维码（群号 942758906，点击可复制群号）与微信群二维码卡片。

## 3. 交互

- 所有区块通过 `v-reveal` 指令（useRevealOnScroll）进入视口渐显，动画遵循 `prefers-reduced-motion`；
- 记忆地图 SVG 节点鼠标悬浮/点击时高亮该节点及关联连线；两处示意图（HeroAppShot 与记忆地图）的消息卡片连线统一由 `src/utils/edgePath.ts` 的 `smoothEdgePath` 生成——锚点取卡片边缘中点（可 along 偏移），控制点沿边缘法线外伸，保证切线垂直卡片边缘、无折角；数据只声明「起始卡片边 → 目标卡片边」；
- 动态展示组件均由 useOnceVisible 首次进入视口触发入场动画：HeroAppShot 连线绘制 + 消息浮现 + 假鼠标演示循环（约 8.4s 一轮，勾选 → Pin → 复位重播），MemoryPinShot Pin 高亮脉冲，GraphShot 节点 rAF 漂移（悬浮节点高亮关联节点与连线，其余淡出）；solid 连线绘制完成后有 SMIL animateMotion 流动光点暗示引用方向；
- 全部组件动画遵循 `prefers-reduced-motion`：GraphShot 漂移不启动，其余直接呈现最终状态；
- 统计数字、时间线、终端打字动画均由 useOnceVisible 首次进入视口触发，其中时间线与打字动画循环重放；
- 群号按钮点击复制群号到剪贴板（2 秒反馈）；
- 「立即体验」「现在就试」跳转 `/chat` 对话页；GitHub 按钮外链开源仓库。

## 4. 主题与响应式

- 支持浅色 / 深色主题，随全局主题切换（apple-gray 色板 + brian-blue 强调色）；动态展示组件为应用深色窗口形态，两种主题下均以深色呈现（与原截图一致）；
- 移动端：统计 2 列、卡片单列、交流群卡片单列，锚点子导航横向滚动；HeroAppShot 左右分屏在窄屏折叠为上下两栏。
