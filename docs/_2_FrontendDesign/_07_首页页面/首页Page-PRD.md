# 首页

## 1. 页面功能

产品宣传首页（系统默认落地页，路由 `/`）。面向新用户介绍 Brian-Agent 的核心亮点：记忆地图、记忆成长、思考透明、第二大脑、数据归属；并提供产品截图、对比表、快速上手指引与社区（QQ / 微信群）入口。内容由根目录宣传页 `BrianAgent.html` 移植而来，视觉风格与前端设计体系（apple-gray / brian-blue / glass-panel、明暗主题）对齐。

## 2. 布局

### 2.1. 整体结构

页面自上而下分为：
1. **全局 Header**：与其他功能页共用（见 整体页面-PRD）；
2. **锚点子导航**：固定在 Header 下方（sticky），提供页内锚点：记忆地图 / 越长越懂你 / 可见的思考 / 第二大脑 / 数据归属 / 对比 / 交流群，右侧「立即体验」按钮跳转 `/chat`；
3. **内容区块**（单向滚动，均带进入视口渐显动画）：
   - **Hero**：标语「AI 的记忆，不该是黑盒」、产品总览截图（hero-map.png）、CTA（▸ 现在就试 → `/chat`；看看它长什么样 → 锚点）；
   - **数据统计**：4 项指标（4 种记忆检索维度 / 13+ 家模型提供商 / 100% 数据留在本机 / 0 依赖安装），进入视口时数字滚动动画；
   - **痛点场景**：对话气泡演示（第 50 轮忘了第 3 轮）；
   - **01 记忆地图**：可交互 SVG 示意图（节点悬浮高亮关联连线、连线入场绘制动画）+ Memory Pin 截图 + 特性清单；
   - **02 越长越懂你**：涌现图 / 关键词图截图（漂浮动画）+ 3 张特性卡片；
   - **03 可见的思考**：需求确认弹窗示意 + 执行时间线示意（进入视口后逐步点亮并循环）+ 特性清单；
   - **04 第二大脑**：6 张特性卡片（资料库 / 自学习 / 选中即问 / 洞察 / 主动度 / 用户画像）；
   - **05 数据归属**：4 张特性卡片（全本机 / API Key 自管 / 解压即用 / 开源自建）；
   - **现在就试**：终端打字动画（npm i -g brian-agent …，循环重放）+ GitHub 外链 + 返回亮点锚点；
   - **对比表**：8 行「常见聊天产品 vs Brian-Agent」对比；
   - **交流群**：QQ 群二维码（群号 942758906，点击可复制群号）与微信群二维码卡片。

### 2.2. 资源

页面图片统一存放于 `src/assets/home/`：hero-map.png、memory-pin.png、tag-graph.png、keyword-graph.png、qr-qq.jpg、qr-wechat.jpg。

## 3. 交互

- 所有区块通过 `v-reveal` 指令（useRevealOnScroll）进入视口渐显，动画遵循 `prefers-reduced-motion`；
- 记忆地图 SVG 节点鼠标悬浮/点击时高亮该节点及关联连线；
- 统计数字、时间线、终端打字动画均由 useOnceVisible 首次进入视口触发，其中时间线与打字动画循环重放；
- 群号按钮点击复制群号到剪贴板（2 秒反馈）；
- 「立即体验」「现在就试」跳转 `/chat` 对话页；GitHub 按钮外链开源仓库。

## 4. 主题与响应式

- 支持浅色 / 深色主题，随全局主题切换（apple-gray 色板 + brian-blue 强调色）；
- 移动端：统计 2 列、卡片单列、交流群卡片单列，锚点子导航横向滚动。
