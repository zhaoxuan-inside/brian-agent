# 配置页面产品需求文档 (PRD)

## 1. 文档概述

### 1.1 产品背景
系统配置项分散且层级复杂，缺乏统一的管理视图。需构建一个五层架构的配置中心，支持全局浏览、精准定位、状态感知及黑暗模式，提升配置管理效率与体验。

### 1.2 核心目标
-   **结构化**：通过五层钻取式架构（框架→分层→模块→分类→配置）管理全量配置。
-   **可视化**：以颜色语义（绿/灰）直观区分可配置状态，L1 提供全局拓扑概览。
-   **高效性**：支持全局搜索、原地编辑、面包屑跳转，减少操作路径。
-   **适应性**：完整支持亮色/黑暗模式切换，适配长时间运维场景。

## 2. 功能架构

### 2.1 五层导航模型

| 层级 | 名称 | 展示形式 | 核心内容 | 交互方式 |
| :--- | :--- | :--- | :--- | :--- |
| L1 | 整体框架层 | 矩形分块拓扑图 | 系统全量分层、模块、分类结构；读写权限控件；状态热力图 | 点击区块进入 L2；支持缩放/平移 |
| L2 | 分层区 | 卡片网格 | 模块列表（名称、描述、分类数、状态标识） | 点击卡片进入 L3 |
| L3 | 模块区 | 卡片网格 | 配置分类列表（名称、描述、配置数、状态标识） | 点击卡片进入 L4 |
| L4 | 配置区 | 卡片列表 | 配置项列表（名称、描述、值摘要、状态标识） | 简单项原地编辑；复杂项点击进入 L5 |
| L5 | 配置读写区 | 侧滑抽屉/弹窗 | 动态表单、Diff 对比、历史版本、提交/取消 | 修改后提交；支持 JSON/文本/枚举/布尔等类型 |

### 2.2 全局功能
-   **全局搜索**：支持 `Ctrl/Cmd + K` 唤起，搜索配置项/模块名，结果展示完整路径，点击直达目标层级。
-   **面包屑导航**：格式为 `整体框架 > 分层 > 模块 > 分类 > 配置`；每级支持下拉菜单快速切换同级节点。
-   **主题切换**：支持亮色/黑暗模式手动切换，自动跟随系统偏好，状态持久化。
-   **双入口同步**：配置页面与独立路由页面（/models, /soul 等）数据实时同步，任一入口修改即时生效。

## 3. 详细功能说明

### 3.1 L1 整体框架层
-   **布局**：采用 Treemap 或自适应矩形分块图，面积映射配置项数量/重要性。
-   **状态指示**：
    -   🟢 绿色系：该区块下有可配置项。
    -   ⚪️ 灰色系：该区块下无可配置项或无权限。
    -   🔴 红色角标：存在配置错误/缺失。
    -   🟡 黄色角标：存在未保存修改。
-   **权限控件**：每个分层/模块区块右上角提供“可读/可写”开关，控制下级访问权限。
-   **响应式降级**：窄屏/移动端自动切换为折叠树形列表。

### 3.2 L2/L3 卡片网格
-   **卡片信息**：标题（加粗）、描述（辅助色）、统计数字（右对齐）、状态色条（左侧 4px）。
-   **交互反馈**：Hover 时上浮 4px + 阴影加深（亮色）或边框提亮（暗色）；灰色卡片降低透明度 + 移除手型光标。
-   **空状态**：无数据时展示插画 + 引导文案（如“暂无可配置模块，请联系管理员”）。

### 3.3 L4 配置列表
-   **原地编辑**：Switch、Input、Select 类型直接在列表行内渲染控件，失焦或回车即触发保存。
-   **批量操作**：支持多选 + 批量启用/禁用/导出。
-   **值摘要脱敏**：API Key、密码等敏感字段显示为 `sk-****abcd`。
-   **复杂项入口**：JSON、对象类型显示“编辑”按钮，点击进入 L5。

### 3.4 L5 配置读写区
-   **容器**：优先使用右侧滑出抽屉（保留 L4 上下文）；仅当表单过宽时使用居中弹窗。
-   **动态表单**：
    -   Text/Number：标准输入框，URL 类型附带“连通性测试”按钮。
    -   Select：下拉选项附带 Tooltip 说明。
    -   Switch：带标签的开关组件。
    -   JSON：集成 Monaco Editor，支持语法高亮、格式化、Schema 校验、模板导入。
-   **变更确认**：提交前展示 Diff 对比视图（旧值 vs 新值），高亮差异部分。
-   **接口路由**：根据配置 type/module 自动分发至 updateConfigPrivilege、manageLLMProvider 等对应接口。

### 3.5 配置模块覆盖范围

| 模块 | 配置内容 | 对应独立路由 |
| :--- | :--- | :--- |
| LLM 模型 | 提供商管理、模型启停、默认模型、连接测试 | /models |
| Soul | Soul CRUD、内容编辑 | /soul |
| Work | Work 配置管理 | /work |
| Skill | Skill CRUD、内容编辑 | /skill |
| MCP | 提供商管理、安装/卸载、启停 | - |
| Agent | 自定义 Agent CRUD、Agent 配置 | /agent |

## 4. 视觉与交互规范

### 4.1 颜色语义系统

| 语义 | 亮色模式 | 黑暗模式 | 用途 |
| :--- | :--- | :--- | :--- |
| 可配置 | green-600 | emerald-400 | 状态标识、色条、图标 |
| 不可配置 | gray-400 | slate-600 + opacity-60 | 禁用态、无权限 |
| 错误/冲突 | red-600 | rose-400 | 校验失败、配置缺失 |
| 警告/待确认 | amber-500 | amber-400 | 未保存、兼容性提示 |
| 已修改 | blue-500 | sky-400 | 本地修改未提交 |

### 4.2 黑暗模式专项规范
-   **表面层级**：通过亮度区分而非边框。L0 底色 Slate-950 → L1 区块 Slate-800 → L5 抽屉 Slate-900 + 边框。
-   **文字层级**：主标题 zinc-100、正文 zinc-300、辅助 zinc-500；禁止纯白 #FFFFFF 大面积使用。
-   **输入框**：bg-slate-800 + border-slate-700 + focus:ring-brand-500/20；避免纯黑凹陷感。
-   **过渡动画**：所有颜色属性添加 transition-colors duration-200，防止切换闪烁。
-   **资源适配**：SVG 使用 currentColor；位图/插画提供暗色版本或叠加 brightness-75 contrast-110 滤镜。
-   **滚动条**：thumb: slate-700, track: transparent。
-   **焦点环**：ring-2 ring-brand-400 ring-offset-2 ring-offset-slate-900。

### 4.3 通用交互规范
-   **加载状态**：L1 框架图使用骨架屏；L2-L4 卡片使用 Shimmer 效果；L5 表单提交时按钮 Loading + 禁用。
-   **成功反馈**：L5 提交成功后 Toast 提示 + 自动关闭抽屉 + L4 列表乐观更新。
-   **错误处理**：接口失败时 Toast 报错 + 保留表单内容不丢失；网络异常时显示重试按钮。
-   **键盘支持**：Tab 顺序合理；Enter 提交；Esc 关闭抽屉/弹窗；搜索框支持上下键选择结果。

## 5. 数据与接口

### 5.1 核心接口

| 接口 | 方法 | 用途 | 备注 |
| :--- | :--- | :--- | :--- |
| getConfigDetail | GET | 获取全量配置树结构 | L1 初始化；建议缓存 |
| updateConfigPrivilege | POST | 更新配置读写权限 | L1 权限控件、L5 权限变更 |
| manageLLMProvider | POST | LLM 提供商相关配置 | L5 按 module 路由 |
| updateConfigValue | PUT | 通用配置值更新 | L4 原地编辑、L5 表单提交 |
| getConfigHistory | GET | 获取配置变更历史 | L5 Diff 对比、版本回滚 |
| testConnection | POST | 测试配置连通性 | L5 URL/API Key 测试按钮 |

### 5.2 数据结构要求
-   getConfigDetail 返回树形 JSON，每个节点包含：id, name, description, type, configurable (boolean), readable (boolean), writable (boolean), children[], valueSummary, relatedRoute。
-   配置项节点额外包含：valueType (string/number/boolean/enum/json), currentValue, schema (用于动态表单渲染)。

## 6. 非功能性需求

-   **性能**：L1 全量数据加载 < 2s（配置项 < 1000）；超过 1000 项时启用虚拟滚动或懒加载子级。
-   **无障碍**：所有颜色对比度 ≥ 4.5:1 (WCAG AA)；支持屏幕阅读器；键盘完全可操作。
-   **兼容性**：Chrome/Edge/Firefox/Safari 最新两个主版本；最小宽度 375px（移动端降级视图）。
-   **安全**：敏感配置传输加密；L4/L5 脱敏展示；权限变更需二次确认；操作日志完整记录。
-   **国际化**：所有文案支持 i18n；配置名称/描述优先展示当前语言，回退至英文。

## 7. 验收标准

-   [ ] 五层钻取导航流畅，面包屑任意层级跳转正确。
-   [ ] 绿色/灰色状态在所有层级准确反映配置可用性。
-   [ ] 全局搜索结果准确，点击直达目标。
-   [ ] L4 原地编辑对 Switch/Input/Select 生效，失焦自动保存。
-   [ ] L5 JSON 编辑器语法高亮、校验、格式化正常。
-   [ ] 黑暗模式切换无闪烁，所有组件颜色层级正确，文字可读。
-   [ ] 敏感信息在 L4/L5 正确脱敏。
-   [ ] 配置修改后，独立路由页面数据同步更新。
-   [ ] 移动端 L1 自动降级为树形列表，基础操作可用。
-   [ ] 键盘 Tab/Enter/Esc 操作符合预期，焦点环清晰可见。
