## 模块 1: 认证与登录

### TC-LAYOUT-001: 首次访问 - 无密码时显示设置密码界面
- **优先级**: P0
- **前置条件**: localStorage 中无 `brian-auth` 数据
- **测试步骤**:
  1. 打开页面
- **预期结果**:
  - 显示 `LoginPage` 组件
  - 标题显示 "Brian"
  - 输入框提示为 "设置密码"
  - 按钮文案为 "设置"
  - 不显示 Header 导航栏

### TC-LAYOUT-002: 已设置密码时显示登录界面
- **优先级**: P0
- **前置条件**: localStorage 中 `brian-auth` 的 `hash` 字段存在
- **测试步骤**:
  1. 模拟 localStorage 存在 `brian-auth` 记录（登录已过期）
  2. 打开页面
- **预期结果**:
  - 显示 `LoginPage` 组件
  - 输入框提示为 "输入密码"
  - 按钮文案为 "登录"

### TC-LAYOUT-003: 登录成功显示主框架
- **优先级**: P0
- **前置条件**: 已设置密码，未登录
- **测试步骤**:
  1. 输入正确密码
  2. 点击登录按钮
- **预期结果**:
  - 界面切换到主框架
  - 显示 `NeuralBackground` 背景动画
  - 显示 `Header` 导航栏
  - `<router-view>` 渲染默认页面（对话页面 `/`）
  - `sessionStorage` 中写入 `brian-session` token

### TC-LAYOUT-004: 登录失败提示错误
- **优先级**: P1
- **前置条件**: 已设置密码
- **测试步骤**:
  1. 输入错误密码
  2. 点击登录按钮
- **预期结果**:
  - 显示错误提示（Toast 或内联错误信息）
  - 输入框保留内容
  - 不跳转到主框架

### TC-LAYOUT-005: 会话过期重新要求登录
- **优先级**: P1
- **前置条件**: 已登录但 session token 过期（7天）
- **测试步骤**:
  1. 模拟 session token 过期
  2. 刷新页面
- **预期结果**:
  - 显示 `LoginPage` 登录界面
  - 不显示主框架

### TC-LAYOUT-006: 锁屏功能
- **优先级**: P2
- **前置条件**: 已登录
- **测试步骤**:
  1. 点击 Header 右上角锁图标
- **预期结果**:
  - 清除 session token
  - 显示 `LoginPage` 登录界面
  - 保留密码 hash

## 模块 3: 暗模式切换

### TC-LAYOUT-013: 暗模式默认跟随系统主题
- **优先级**: P1
- **前置条件**: localStorage 中无 `brian-theme` 数据
- **测试步骤**:
  1. 系统设置为浅色模式，打开页面
  2. 系统设置为深色模式，打开页面
- **预期结果**:
  - 浅色系统 → 页面为浅色模式，`<html>` 无 `dark` class
  - 深色系统 → 页面为深色模式，`<html>` 有 `dark` class

### TC-LAYOUT-014: 暗模式手动切换
- **优先级**: P0
- **前置条件**: 已登录
- **测试步骤**:
  1. 当前浅色模式，点击太阳图标
  2. 当前深色模式，点击月亮图标
- **预期结果**:
  - 浅色→深色：`<html>` 添加 `dark` class，图标切换为月亮
  - 深色→浅色：`<html>` 移除 `dark` class，图标切换为太阳

### TC-LAYOUT-015: 暗模式状态持久化
- **优先级**: P1
- **前置条件**: 已登录
- **测试步骤**:
  1. 切换到深色模式
  2. 刷新页面
- **预期结果**:
  - 页面保持深色模式
  - localStorage 中 `brian-theme` 值为 `dark`
