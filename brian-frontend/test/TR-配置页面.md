## 模块 1: L1 整体框架层

### TC-CONFIG-001: L1 框架图加载
- **优先级**: P0
- **测试步骤**: 1. 导航到 `/config`
- **预期结果**: 显示矩形分块拓扑图（Treemap），展示系统的全量分层、模块、分类结构

### TC-CONFIG-002: L1 状态颜色指示
- **优先级**: P0
- **测试步骤**: 1. 查看 L1 框架图各区块颜色
- **预期结果**:
  - 有可配置项 → 绿色系 (green-600)
  - 无可配置项/无权限 → 灰色系 (gray-400)
  - 存在配置错误 → 红色角标
  - 存在未保存修改 → 黄色角标

### TC-CONFIG-003: L1 权限控件
- **优先级**: P1
- **测试步骤**: 1. 查看 L1 各区块右上角 2. 点击可读/可写开关
- **预期结果**: 显示权限开关控件，点击后调用 `updateConfigPrivilege` 接口

### TC-CONFIG-004: L1 点击进入 L2
- **优先级**: P0
- **测试步骤**: 1. 点击 L1 中某个分层区块
- **预期结果**: 导航到 L2 该分层的模块卡片网格

### TC-CONFIG-005: L1 缩放/平移
- **优先级**: P1
- **测试步骤**: 1. 滚轮缩放 L1 框架图 2. 拖拽平移
- **预期结果**: 框架图支持缩放和平移交互

### TC-CONFIG-006: L1 骨架屏加载
- **优先级**: P2
- **测试步骤**: 1. 首次加载配置页面时
- **预期结果**: L1 框架图显示骨架屏等待数据

### TC-CONFIG-007: L1 响应式降级（移动端）
- **优先级**: P2
- **测试步骤**: 1. 设置窗口宽度 375px
- **预期结果**: L1 自动切换为折叠树形列表
