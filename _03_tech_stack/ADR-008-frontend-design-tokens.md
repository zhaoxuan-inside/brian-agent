# ADR-008 前端设计令牌体系(本次 R2)

> 状态:accepted　日期:2026-09-26

## 背景
各页面样式硬编码、口径不一(_05 任务卡盘点),需"人性化"统一:可读层级、舒适间距、一致反馈、可访问性。

## 决策
S1 方案:零新依赖。在 tailwind.config 扩展语义色板/字号层级/间距/圆角/阴影/动效 tokens,全局 CSS 建立 CSS 变量与基础态(焦点环/滚动条/选区/过渡);逐页将硬编码样式收敛到 token;补齐空态/加载态/错误态。

## 备选方案
| 方案 | 未选原因 |
|---|---|
| 引入 Element/Naive UI 等组件库重写 | 破坏零依赖定位,回归面大(_02 B1) |

## 后果
- 正面:视觉一致性可持续演进;不破坏既有组件 API。
- 负面:令牌纪律需靠评审维持(_09 词典登记 token 命名)。
